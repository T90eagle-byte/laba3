# NEXT PROMPT

Ниже готовый промпт для продолжения работы:

---

Ты работаешь с существующим Flask-проектом аптеки.  
Нужно продолжить с текущего checkpoint.

Контекст:
- D2C/design_export уже частично перенесен в `app/static` и `app.css`.
- В `base.tpl` уже есть общий header/layout и flash-сообщения.
- Session-корзина уже добавлена (`/cart`, `/cart/add`, `/cart/remove`, `/cart/checkout`).
- Старая форма заказа `/orders/form/0` должна продолжать работать.

Критические ограничения:
1. Не создавать новую Cart-модель в БД.
2. Не делать миграции.
3. Не переписывать проект с нуля.
4. Оставить Flask, Flask-Login, Flask-WTF.
5. Сохранить админку.
6. Сохранить session cart как основной механизм.
7. Сохранить старый flow заказа через `/orders/form/0`.
8. Backend менять только точечно.

Этап A: стабилизация backend-корзины (сначала это)
- Проверить и при необходимости доработать:
  - пустая корзина и checkout пустой корзины;
  - несуществующие товары в add/remove/checkout;
  - товары, удаленные админом, но оставшиеся в session;
  - корректность quantity и cart counter в header;
  - очистка корзины после checkout;
  - отображение заказа после checkout в `/orders`;
  - совместимость со старым `/orders/add` flow.
- Все операции изменения корзины оставить только POST + login_required.

Этап B: точечная отрисовка дизайна
- После стабилизации backend перейти к аккуратной визуальной доводке:
  - `catalog` / `cart` / `orders` / `profile` / `login` / `register`.
- Не копировать D2C HTML целиком, адаптировать под существующие Jinja-шаблоны.
- Не ломать `module_url`, WTForms, action/method/name/value полей.

Проверки после изменений:
- `python -m py_compile main.py`
- `python -m py_compile app/pharmacy.py`
- `python -m py_compile app/forms.py`
- Проверить страницы: `/products`, `/cart`, `/orders`, `/profile`, `/admin`
- Проверить добавление/удаление товара из корзины и checkout.

Формат отчета:
1. Список измененных файлов.
2. Что исправлено в backend.
3. Что изменено в шаблонах/дизайне.
4. Какие сценарии проверены.
5. Какие ограничения остались.
