# Console Client для ЛР4

Консольный клиент работает с Flask-приложением аптеки через REST API и не обращается напрямую к SQLite или pickle.

## Запуск Flask-сервера

Из корня проекта:

```powershell
python main.py
```

По умолчанию Flask-приложение запускается на `http://127.0.0.1:8000`, если переменная `PORT` не переопределена. Для клиента удобно запустить сервер на 5000:

```powershell
$env:PORT=5000
python main.py
```

## Запуск клиента

```powershell
python console_client/main.py
```

По умолчанию клиент использует:

```text
http://127.0.0.1:5000
```

Адрес можно изменить через переменную окружения:

```powershell
$env:PHARMACY_API_URL="http://127.0.0.1:8000"
python console_client/main.py
```

Если приложение опубликовано под другим адресом или меняется идентификатор модуля, достаточно изменить `PHARMACY_API_URL`. Клиент использует только относительные REST-маршруты `/api/...`.

## Возможности

- вход через `/api/auth/login`;
- просмотр текущего пользователя через `/api/auth/me`;
- каталог товаров, поиск и фильтр категории;
- просмотр заказов;
- создание, изменение и удаление заказа;
- выход через `/api/auth/logout`.
